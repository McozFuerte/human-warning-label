One-line safety warning label that should come printed on every human being. Entry for the make.fun Warning Label for Humans comedy bounty.

## Run it

```
python3 main.py
```

Writes one line to `/output/entry.txt`. Override the output directory with `OUTPUT_DIR` env var.
